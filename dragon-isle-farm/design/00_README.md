# Dragon Isle Farm — Visual Design Pack

**Status:** Draft for review · **Date:** 5 Oct 2026 · **Nothing in Roblox Studio has changed yet.**

These files describe how every item in the game should look. Review them, tick the checklists (or write notes), and send back what to change. Once approved, the designs get built in Studio.

## Files

| File | What's inside | Items |
| --- | --- | --- |
| `01_Art_Direction.md` | Research findings, style rules, palette, how rarity and mutations look, performance budget, originality rules | Rules for everything below |
| `02_Seeds_and_Crops.md` | Seed pouches, 4 growth stages, harvested crops | 11 crops |
| `03_Pets.md` | Concept, palette, build, signature and idle animation for each pet | 18 pets |
| `04_Eggs_and_Hatching.md` | Shop eggs, Breeding Nest egg, hatch reveal sequence | 3 eggs + nest egg |
| `05_Gem_Store_Items.md` | Gear, upgrades and cosmetics | 5 items |
| `06_World_NPCs_and_UI.md` | NPCs, shop buildings, farm plot, nest, village, lighting, currency icons, UI | 2 NPCs + world |

## Suggested review order

1. `01_Art_Direction.md` first. If the style rules or rarity look change, everything else follows.
2. Then any order. Each file ends with a checklist table.

## What these designs do *not* change

Prices, grow times, odds, bonuses and Gem rewards stay exactly as in `GameConfig`. Only visuals are designed here, except two optional ideas that would need code and are marked as optional:

- Random crop size variants at harvest (`01_Art_Direction.md` §5)
- Player-chosen banner colours (`05_Gem_Store_Items.md`)

## Build plan after approval

1. Lighting preset and rarity effects (quick wins that lift everything).
2. Crops: per-stage models and mutation looks.
3. Pets, Common to Divine.
4. Eggs and the hatch reveal.
5. Gem Store items, NPCs, shop buildings and plot details.
6. UI icons for Ru, Gems and every item.
